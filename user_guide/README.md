# Agentic-J User Guide

Agentic-J is an assistant for image analysis. You describe what you want in the chat, and it does the work in Fiji, napari and Python, saving every script, result and figure in a project folder on your computer.

| Guide | What you will find there |
|-------|----------|
| [01 Getting started](01_getting_started.md) | What you need, the `.env` file, starting and stopping Agentic-J, using a graphics card |
| [02 The interface](02_interface_and_agents.md) | The chat window, the buttons, the three modes, the helpers working behind the scenes, plugins, settings |
| [03 Writing good requests](03_prompting.md) | What to tell the assistant, examples, tips |
| [04 Your files, chats and reports](04_data_history_and_reports.md) | Where results are saved, chat history, cost reports, reporting a problem |
| [05 Security and privacy](05_security.md) | What is sent to the AI provider, what stays on your computer, the Vision Judge |
| [06 napari, segmentation and fine-tuning](06_napari_and_fine_tuning.md) | napari in the chat, micro-sam, teaching a model on your own corrections, sorting objects into classes |
| [07 Learning mode](07_learning_mode.md) | Learning bioimage analysis with the built-in course |

For help or bug reports, use the **Report Issue** button in the chat window or email **agentj.help@gmail.com**.
