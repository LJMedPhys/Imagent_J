# Learning Mode

Agentic-J can also teach you bioimage analysis. In learning mode it works as a tutor, using a course based on Pete Bankhead's free book [*Introduction to Bioimage Analysis*](https://bioimagebook.github.io) (CC-BY 4.0).

## How to start

Just ask, for example:

> "Teach me about thresholding."

> "What is bit depth, and why does it matter?"

> "I'd like to learn bioimage analysis from the beginning."

The assistant switches to learning mode by itself. When you want to analyse your own images again, say so ("now let's threshold my images") and it switches back.

## What it covers

| Part | Topics |
|---|---|
| Introducing images | Images and pixels, measurements and histograms, bit depth, channels and colours, pixel size, file formats |
| Processing and analysis | Point operations, thresholding, filters, morphological operations, image transforms, working with stacks and time series |
| Fluorescence microscopy | From photons to pixels, blur and the point spread function, noise, microscopes and detectors |
| Extras | A short introduction to Python, and writing ImageJ macros |

## What the tutor does

- **Explains ideas step by step**, adapting to what you already know, and shows the book's figures in Fiji.
- **Shows short live demonstrations** in Fiji or Python, using the course's example images, so you can see an idea in action.
- **Lets you choose between Fiji and Python** for the hands-on parts.
- **Gives practice exercises** and reveals the solution when you ask.
- **Explains any open Fiji window** if you ask ("what does this setting do?").
- **Remembers your progress** within the chat, so you can come back to the same chat and continue where you left off.

The tutor doesn't run a full analysis on your own data. For that, ask it to switch back, as described above.
