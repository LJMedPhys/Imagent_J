AI agent for biological microscopy image analysis

From raw micrographs
to publication,
in one conversation.

Agentic-J runs Fiji, Python and napari in one container, next to a chat panel. It plans the analysis, writes and debugs the code, checks every result by eye with a vision-language judge, fine-tunes segmentation models on your corrections and documents the whole project. It can also teach you bioimage analysis from the ground up.

What's inside

A full analysis team, not a chatbot.

  • Dialog help: it screenshots an open plugin dialog and explains each parameter

Python

CONDA ENVS · STATS · PUBLICATION PLOTS

The Python analyst writes scripts for the scientific Python stack. A one-line header selects which of the container's conda environments the script runs in.

  • Segmentation: Cellpose 3 and Cellpose-SAM, batch over folders
  • Spots & features: Big-FISH, cp_measure (the CellProfiler feature set)
  • Atlases: BrainGlobe registration to neuroanatomical atlases
  • Stats & plots: scikit-learn, rigorous tests, 300-DPI PNG + SVG figures

napari

MCP · 3D · INTERACTIVE

A napari viewer is available through the Model Context Protocol. The agent opens layers, adjusts views and hands you tools, and napari opens only when a task needs it.

  • micro-sam: Segment Anything for Microscopy, automatic or promptable
  • 3D & n-D: volumes and time series that 2D viewers struggle with
  • Object classifier: train on a few clicks, then apply to a batch
  • Annotation: the viewer where you correct masks for fine-tuning

Fig. 3 · Human-in-the-loop fine-tuning

When the stock model is wrong, teach it.

You never annotate a whole image. You pick a few small tiles and correct them in napari, and the agent does the rest: it trains, evaluates, and applies the model only after checking the result.

1

Pick tiles

In napari, you choose the regions that matter, such as a crowded cluster or a dim cell. A blob count can't tell debris from a cell, but you can.

you~3 min
2

Correct

The current model pre-segments each tile, so you only fix its mistakes. You don't draw from scratch.

you2–4 min / tile
3

Train

The agent fine-tunes micro-sam or Cellpose on your corrections, on the GPU when available.

agent10–20 min
4

Measure & apply

The new model is scored against the stock one before anything uses it. Then it runs on the whole dataset.

agent~1 s / image

Three good tiles are worth more than a whole bad image.

Fine-tuning works with both micro-sam and Cellpose. Stages 1 and 2 are shared, so you can run the stock models first, compare their overlays, and fine-tune whichever is closest.

The agent notices when you're unhappy. If you keep rejecting segmentations, the watchdog stops retrying new parameters and suggests fine-tuning on your own annotations instead.
Fig. 4 · Visual quality control

A second pair of eyes on every step.

A script that runs without errors can still produce wrong results. The optional VLM judge looks at the actual pixels: the input, each segmentation overlaid on its source, and the final plots.

  • Deterministic overlays: the mask is alpha-blended onto the original before the model sees it, so the judge compares Original, Mask and Overlay side by side.
  • Typed verdicts: PASS, WARN, FAIL or INFO, with a summary and a recommended action that the supervisor must act on.
  • Never blocks the pipeline: if the judge is unavailable, it returns a WARN and hands the check to you rather than crashing.
  • Any format: PNGs are read directly, and every other bioimage format is opened in Fiji and rendered first.

Fig. 6 · Guardrails

Built to be trusted with real data.

Autonomy is only useful if you can rely on it. These safeguards run on every turn.

Agent watchdog

Detects an agent that repeats the same call, stalls on a hung tool, or runs on without end, and stops it cleanly so the supervisor still gets a structured hand-off.

Script watchdog

Supervises every Groovy and Python run and ends runaway scripts instead of letting them block the session.

Learned memory

A background librarian records the pitfalls and working recipes from past runs, and the agents recall them the next time the same problem comes up.

State ledger & phases

A shared state_ledger.json records every step. A phase guard stops the pipeline from skipping ahead, for example to plotting before the I/O check.

QA reporter

An optional, read-only auditor that checks the project against community checklists for publishing image data and writes a report.

Secure by design

Bound to localhost, runs as a non-root user with all Linux capabilities dropped, and sees only ./data/. Your data stay on your machine.

Choose the model for each role.

Works with an OpenAI or an OpenRouter key. With OpenRouter, any provider's model can fill any role. Set each role's model and reasoning effort in one file, and turn the optional agents on or off, without rebuilding. 

# imagentj_config.yaml
models:
  supervisor: "openai/gpt-5.4"
  worker:     "openai/gpt-5.3-codex"  # coder + debugger
  analyst:    "openai/gpt-5.3-codex"
  curator:    "openai/gpt-5.4-mini"   # librarian
  vlm:        "google/gemini-3.5-flash"
reasoning_effort:
  vlm: high

Get started

Up and running in four steps.

You'll need Docker, about 8 GB of RAM, about 30 GB of free disk, and an OpenAI or OpenRouter API key.

i.

Clone the repo

Install Git and Git LFS, because the knowledge base is stored with LFS.

git lfs install
git clone https://github.com/MMV-Lab/Agentic-J.git
cd Agentic-J
ii.

Add your key

Copy the template and fill in one key. If you skip this step, a setup wizard will ask for it.

cp .env.template .env
# then set one of:
OPENAI_API_KEY=sk-...
OPEN_ROUTER_API_KEY=sk-...
iii.

Add your images

Put your files in ./data/. The agent sees them at /app/data.

Agentic-J/
├── data/
│   └── my_image.tif
├── .env
└── docker-compose.yml
iv.

Launch

When it's ready, open localhost:6080/vnc.html in your browser.

docker compose up

Have an NVIDIA GPU?

The GPU build accelerates Cellpose, StarDist, micro-sam and fine-tuning. It needs driver 560+, nvidia-container-toolkit and CDI enabled in Docker. GPU guide →

docker compose -f docker-compose.yml \
  -f docker-compose.gpu.yml up -d
