From raw micrographs
to analytical validation,
in one conversation.

Agentic-J is an AI agent that analyses microscopy images with the tools the community already trusts: Fiji and its plugins, the scientific Python stack and napari. Describe your question in plain English. It adapts the analysis to your data, picks the right plugin or library, writes and debugs the code, and documents the whole project. If a tool is missing, it can install it.

Community tools

Fiji, Python and napari in the same chat.

Agentic-J builds on the plugins and libraries the bioimage community develops and validates, and picks the right one for each step. Each tool below comes with a curated skill that the agent loads when needed. Need something else? Ask the agent to install it.

Fiji / ImageJ

Install

Install in four steps.

You'll need Docker, at least 8 GB of RAM, 50 GB of free disk, and an OpenAI or OpenRouter API key.

i.

Clone the repo

Install Git and Git LFS, because the knowledge base is stored with LFS.

git lfs install
git clone \
  https://github.com/MMV-Lab/Agentic-J.git
cd Agentic-J
ii.

Add your key

Copy the template and fill in one key. If you skip this step, a setup wizard will ask for it.

cp .env.template .env
# then set one of:
OPENAI_API_KEY=sk-...
OPEN_ROUTER_API_KEY=sk-...
iii.

Add your images

Put your files in ./data/. The agent sees them at /app/data.

Agentic-J/
├── data/
│   └── my_image.tif
├── .env
└── docker-compose.yml
iv.

Launch

When it's ready, open localhost:6080/vnc.html in your browser.

docker compose up

Have an NVIDIA GPU?

The GPU build accelerates Cellpose, StarDist, micro-sam and fine-tuning. It needs driver 560+, nvidia-container-toolkit and CDI enabled in Docker. GPU guide →

docker compose -f docker-compose.yml \
  -f docker-compose.gpu.yml up -d

Where your files live

The container sees one folder of your computer. Put your images there, and everything the agent writes appears there straight away.

Demonstrations

One agent, four ways to work.

Let it run the analysis, fine-tune a model with you, guide you click by click, or teach you.

Plugins from a prompt
Demo video · coming soon

Describe what you want to measure. The agent picks a suitable plugin, such as TrackMate, StarDist or MorphoLibJ, writes a Groovy script against its real API, runs it in Fiji and fixes it when the ImageJ log shows an error. You keep the script and can re-run it outside the agent.

Fine-tuning
Demo video · coming soon

Pick a few tiles in napari and correct the current model's mistakes instead of drawing from scratch. The agent fine-tunes micro-sam or Cellpose on your corrections, scores the new model against the stock one, and only then runs it on the whole dataset.

Click by click
Demo video · coming soon

Prefer to stay in control? Say "do this through the menus" and the agent walks you through Fiji step by step instead of writing a script. It can also read an open plugin dialog and explain each parameter.

Teaching mode
Demo video · coming soon

In education mode Agentic-J works as a tutor. It teaches Pete Bankhead's Introduction to Bioimage Analysis (CC-BY 4.0) one chapter at a time, with ImageJ and Python practicals and live demos on the book's sample images.

Reproducibility

Reproducible by default.

Every analysis becomes a self-contained project folder with the raw data, scripts, results, figures and logs. A state ledger records each step as it happens, and at the end the agent writes a workflow report from it.

The project folder

Created by the agent when an analysis starts.

data/projects/my_project/
├── raw_images/              copy of your source images
├── processed_images/
│   ├── channels/            split or pre-processed TIFFs
│   └── montages/            overview images
├── scripts/
│   ├── imagej/              generated Groovy scripts
│   └── python/              stats & plotting scripts
├── data/                    measurement CSVs, tables
├── figures/                 plots, publication figures
├── logs/                    execution logs
├── state_ledger.json
├── Workflow_Documentation.md
└── QA_Checklist_Report.md   if QA is enabled

The state ledger

Excerpt from a real project: BoneJ trabecular morphometry of micro-CT scans. Long values are shortened.

  "key_decisions": [ ... ],
  "image_metadata": {
    "bit_depth": 8, ..., "n_images": 67, ..., "modality": "microCT", ...

  ...

    ...
    {
      "phase": "4b",

The ledger lives on disk and its list of steps is append-only, so it survives context compaction in long sessions.
